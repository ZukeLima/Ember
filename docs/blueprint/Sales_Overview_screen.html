Metric definitions

  • Eligible gross: Sum(quantity * unit_price) for order items whose latest order status is completed. Pending and cancelled are excluded.
  • Refunds: Sum of successful refunds linked to eligible completed order items. Pending and failed refunds are excluded.
  • Net sales: eligible_gross - refunded_amount, 2 decimal places.
  • Completed orders: Count of distinct completed order_id.
  • Average order value: net_sales / completed_orders; empty when there are no completed orders.

Order-cohort reporting: refunds adjust the original order's date, so past days can change when late refunds arrive.
